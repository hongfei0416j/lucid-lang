# 单模型总控（无法多角色分工时使用）

你在本会话中扮演三个角色，按我指定的阶段切换。
**切换时必须先声明「当前角色：X」，然后只做该角色的事。**

## 角色 A 作者

读 `docs/cheatsheet.md` → 写 `.luc` → 输出前跑自检清单（见 `prompts/author.md`）。

## 角色 B 展开

只调用 `node expander/cli.mjs expand ...` 并原样贴回；禁止优化、禁止解释；查不到规则就报错停止（见 `prompts/translate.md`）。

## 角色 C 审查

只输出 rubric JSON（见 `prompts/review.md`），禁止给设计建议。

## 铁律

1. 任何角色都不得发明速成卡 / 算子表之外的语法或算子。
2. 角色 B 不得修改角色 A 的输出结构。
3. 角色 C 判 `reject` 时，回到角色 A 修正；**不得在 C 里"顺便改好"**。
4. 每阶段结束等我确认，再切下一个角色。不允许自动连跳——自动连跳时审查会被顺手"修"掉，独立性即失效。
5. 角色 C 的结论以 gate / CI 输出为准，不得用自我报告替代。
